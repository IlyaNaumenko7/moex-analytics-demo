# MOEX Analytics Demo

Демонстрационный проект аналитической системы для работы с историческими биржевыми данными.

## 🎯 Цель проекта
Демонстрация чистой, модульной архитектуры для загрузки финансовых данных, расчёта технических индикаторов и визуализации результатов. 

> **Примечание:** В данной демо-версии используется генератор реалистичных синтетических данных (`mock_data`). Это гарантирует стабильную работу кода и мгновенную демонстрацию логики без зависимости от временных блокировок, ограничений CORS или изменений во внешних API (MOEX ISS, Yahoo Finance). Архитектура позволяет переключить источник данных на реальный API или локальный CSV заменой всего одного класса.

## 🛠 Стек технологий
- **Python 3.11+**
- **pandas, numpy** — обработка и анализ данных
- **ta** (Technical Analysis Library) — расчёт индикаторов
- **matplotlib** — визуализация результатов
- **pytest** — структура готова для написания автотестов

## 📂 Структура проекта
Проект разделён на логические модули для соблюдения принципа единственной ответственности (SRP):

```text
moex-analytics-demo/
├── src/
│   ├── __init__.py
│   ├── data_loader.py     # Абстракция загрузки данных (легко заменить источник)
│   ├── indicators.py      # Модуль расчёта технических индикаторов
│   ├── visualization.py   # Модуль построения графиков
│   └── mock_data.py       # Генератор реалистичных OHLCV-данных для демо
├── output/                # Директория для сохранения результатов
├── main.py                # Точка входа
├── requirements.txt       # Зависимости проекта
└── README.md
